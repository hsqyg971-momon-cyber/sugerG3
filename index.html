# 依頼内容 HTML5 CanvasとJavaScript（Vanilla JS）を使用して、ブラウザで遊べるカジュアルゲーム「フクロモモンガのポーチダイブ」の完全なコードを作成してください。 HTML、CSS、JavaScriptはすべて単一の「index.html」ファイルにまとめて実装してください。 # 画面仕様・アセット - Canvas解像度: 縦向き（例: 480 × 800px またはレスポンシブな縦長アスペクト比） - キャラクター画像: 同一フォルダ内の画像ファイル `sugar_glider.png` を使用（読み込みエラー時はフォールバックとして茶色の丸と耳を描画） - 背景: 夜空または温かみのある部屋をイメージしたCanvas描画グラデーション # ゲームシステム・ルール 1. 【モモンガの挙動】 - ゲーム開始時、画面上部の枝（またはロープ）につかまり、左右にゆっくり自動で往復運動している。 - 画面をタップ（またはクリック / スペースキー）すると、手を離して真下に落下・滑空を開始。 - 落下中にもう一度タップすると、少しだけ前進（または左右の微調整やゆっくり降下）できるような簡単な滑空アクションを入れてください。 2. 【ターゲット（ポーチ）】 - 画面下部で、吊り下げられた「専用ポーチ」が左右にゆらゆらと周期運動（サイン波）している。 - レベルが上がるにつれてポーチの移動速度や振れ幅が変化する。 3. 【判定と演出】 - 成功判定: モモンガがポーチの口（判定エリア）に飛び込むと成功。 - 成功時はスポッと中に入り、ポーチからひょっこり顔を出すようなアニメーションを再生。 - 得点加算（中心に近いほど高得点のPERFECT/GREAT演出）。 - 失敗判定: ポーチを外して画面外に落下、またはポーチのフチに弾かれるとミスとなりライフが減る（初期ライフ3）。 - 成功/失敗後、少しの間を置いて次のモモンガが上部に現れる。 4. 【UI・ゲームループ】 - スタート画面、プレイ画面、ゲームオーバー画面を状態管理（state）で実装。 - スコア表示、ベストスコア記録（localStorage対応）。 - リトライボタン。 - 外部ライブラリは使用せず、標準Web Audio APIで簡単な効果音（ジャンプ音、スポッと入った成功音、ミス音）をシンセサイズ生成してください。 # コードの要件 - モバイル端末でのタッチ操作（touchstart/touchend）およびPCでのクリック・キー操作の両方に対応。 - 画像のアスペクト比を維持して描画すること。 - コード全体を省略（TODOなど）せず、そのまま動く完全な形で出力してください。
